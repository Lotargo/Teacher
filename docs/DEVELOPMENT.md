# Разработка АГА!

Технические заметки для сопровождающих проект. Публичное описание находится в [README](../README.md).

## Что исполняет редактор

Это **ограниченный учебный интерпретатор, а не полный Python**: print, числа, строки, простые имена, присваивание, арифметика, скобки и комментарии. Нет eval, Function, импорта, циклов, доступа к DOM, сети или файловой системе. Ограничены длина программы, число строк, количество токенов, глубина выражений, величина чисел и размер строк.

Проверка решения анализирует операции, реально участвовавшие в выводимом числовом результате. Комментарий `# 5 + 3`, строка с ответом или неиспользованное вычисление не заменяют требуемую операцию. При этом принимаются скобки, обратный порядок слагаемых и расчёт через переменные.

Отметки и черновики сохраняются в localStorage браузера. Сбой или запрет хранилища не блокируют обучение. Прогресс старой несвязанной версии не переносится автоматически в новые задания.

## Запуск и проверки

Сборка и npm install для сайта не нужны. Откройте корень репозитория через любой статический HTTP-сервер:

```sh
python -m http.server 8000
# http://localhost:8000/
npm test
```

Для тестов нужен Node.js 22+. Основной набор проверяет интерпретатор, критерии решения, содержание заданий и ресурсы страницы.

Дополнительно: `python tests/browser_smoke.py` при наличии Python Playwright и Chromium. Браузерные проверки обслуживают неизменённые файлы через перехват запросов тестового origin под `/Teacher-/`, а не через подмену HTML или localStorage. Это проверяет переходы между настоящими HTML-документами, модули, прогресс и вложенные пути без внешнего сервера. Запросы веб-шрифтов отключены только в тестах: проверяется системный fallback.

Если окружение запрещает навигацию браузера, `python tests/browser_offline.py` отдельно проверяет рендеры и упражнения через встраивание модулей и mock localStorage. Это ограниченная локальная проверка, не подмена полного теста переходов.

## Страницы и содержание

- `/` — главная.
- `/courses/` — каталог.
- `/courses/start/` — знакомство и выбор занятия, не «нулевой курс».
- `/lessons/first-discovery/` — существующая вводная история.
- `/math/` — математика в бытовых примерах, локальный калькулятор скидки.
- `/workshop/` — мастерская идей и локальная сборка задания для ИИ.
- `/library/` — авторские материалы и сторонние ресурсы с контекстом.
- `/library/check-ai/` — статья о проверке результата ИИ.

Открытый проект не продаёт обучение, не выдаёт сертификатов и не обещает трудоустройство. Это пространство для самопроверки, идей, работы и хобби, а не только каталог курсов. Новые учебные разделы статические, без аккаунтов и обязательного backend; облачный чат Пикс использует отдельный Cloudflare Worker. Источники библиотеки ведут на официальные внешние ресурсы; не копировать их содержимое.

`src/catalog.js` — реестр направлений и уроков: заголовки, статусы, пути и ключи прогресса. `src/portal.js` обновляет карточки и кнопки продолжения; он не подменяет документы и не является SPA-роутером. Исходные HTML содержат рабочие ссылки и описание текущего содержания также без JavaScript.

Добавляя направление, создайте отдельную HTML-страницу по образцу `courses/start/index.html`, укажите ID в `data-lessons`, добавьте опубликованные уроки и запись в реестр. Новые занятия получают собственные ключи хранения. Не выдавайте запланированное содержание за доступное. Карточки со статусом `planned` не имеют ссылки.

Проверяйте согласованность статического fallback каталога с реестром; существующие ссылки должны работать без JS. Все HTML используют относительные пути, JS вычисляет корень относительно `import.meta.url`.

## Совместимость и данные

Ключ `aga-connected-story-v2` сохранён: перенос страницы не сбрасывает результаты и черновики. Каталог и занятие используют одно хранилище origin. Повреждённые значения и запрет localStorage не блокируют сайт. Старые ссылки `/#math`, `/#code` и другие якоря урока перенаправляются на вложенный документ только при наличии соответствующего hash.

## Публикация

Существующий GitHub Actions workflow выполняет `npm test` и публикует исходные статические файлы. Сборка и сервер приложения не нужны. Статус публикации проверяется по успешному deploy, а не по одному коммиту.


## Иллюстрации главной

Главная использует пять отдельных изображений в `assets/home/`: команда, бытовой хаос, ночные вопросы, отладка и бумажный сёрфинг. Это подготовленные версии утверждённых иллюстраций, а не снимок макета. Текст, навигация и кнопки остаются HTML.

AVIF сохраняет прозрачность; изображения нормализованы в квадратные холсты 640 px для первого экрана и 480 px для карточек. Главная картинка загружается с высоким приоритетом, остальные — отложенно. Размеры зарезервированы в разметке. Суммарный бюджет пяти файлов — менее 160 kB.

`styles/home.css` подключён только на главной. Движение включается при наличии IntersectionObserver, останавливается вне экрана и в фоновой вкладке; общая кнопка и системный reduced-motion имеют приоритет. `tests/home.test.mjs` проверяет ресурсы и разметку; браузерные проверки проверяют декодирование, ширину, прогресс и движение. `browser_offline.py` — только резервная локальная проверка с встроенными ресурсами и имитацией хранилища, не замена реальным переходам в `browser_smoke.py`.

## Расширение самостоятельных разделов

Глобальная навигация: главная, практика, математика, мастерская, библиотека. Общие статические фрагменты живут в `templates/header.html` и `templates/footer.html`; при новом маршруте добавьте его в `scripts/sync-chrome.mjs`, выполните `npm run chrome` и обновите набор тестовых страниц. Публичный `README.md` остаётся витриной, без команд установки.

`styles/atlas.css` оформляет самостоятельные страницы, не затрагивая типографику и сетку урока. `src/life-math.js` считает проценты из пользовательских значений; `src/workshop.js` собирает текст задания исключительно в браузере, без сохранения и отправки данных; `src/library.js` фильтрует карточки, без скрытия содержания при отключённом JavaScript.

Критерии публикации: проверяемый источник, понятная аудитория и смысл материала, отсутствие фиктивных кнопок и платёжных механизмов. Для работы с ИИ показывать не только промпт, но и проверочные сценарии, риски и возможность отката.


### Пикси: ИИ-чат и локальный интерфейс

`src/pix-guide.js` монтирует одно немодальное окно беседы. Нет переключателя на локальные подсказки и рекламных плашек модели. Приветствие заранее написано в коде, показывается без сети и не добавляется к истории модели. До первой отправки нет `/config`, Turnstile и inference. Краткое пояснение внизу окна раскрывает облачную обработку; FAQ сохраняет информацию о Cloudflare как обработчике данных.

`src/pix-ui.js` отвечает за ограничение координат окна и постепенный вывод. SSE используется через `src/cloudflare-adapter.js`; JSON получает локальное раскрытие текста. Визуальный вывод — только `textContent`. Кнопка «Стоп» отменяет и запрос, и посимвольный вывод. Сбой возвращает вопрос в поле ввода. История и токены только в памяти, никаких журналов переписок или browser storage. До восьми предыдущих реплик и текущий вопрос уходят в Worker. При прокрутке вверх чтение не сбивается новым текстом.

Жёлтая кнопка — звук (включён по умолчанию), зелёная — расширение, красная — закрытие. Web Audio разблокируется жестом пользователя; до взаимодействия звук не обещается. Уведомления не требуют разрешения на системные push. Значок непрочитанного над Пикси появляется для локального приветствия и ответов, завершившихся при закрытом окне или скрытой вкладке. Все движения уважают reduced-motion и кнопку сайта.

Перетаскивание за шапку использует Pointer Events и pointer capture; координаты ограничены экраном. Шапка доступна через Tab; стрелки перемещают окно на 20 px, Shift+стрелка — на 60 px. На мобильных окнах до 600 px перетаскивание отключено. Escape закрывает чат, не останавливая уже запрошенный ответ.

### Cloudflare: публикация сервера отдельно от Pages

Исходники — `cloudflare/worker.js` и `cloudflare/wrangler.jsonc`. Сайт загружает публичный sitekey из `GET /config` при первой отправке. На сервере должны оставаться:

- Workers AI binding `AI`.
- Text variable `TURNSTILE_SITE_KEY` и Secret `TURNSTILE_SECRET`, widget Managed для `lotargo.github.io`.
- Rate-limit `CHAT_LIMITER` (3/60 s на IP) и дополнительный `GLOBAL_LIMITER` (15/60 s на локацию). Это приблизительные ограничения, не строгий дневной бюджет.
- `PILOT_TOKEN` для личных прямых запросов; он никогда не включается в сайт.

`GET /config` сообщает `publicEnabled: true` только при наличии sitekey, secret и CHAT_LIMITER. Все POST проверяют формат, origin и одноразовый токен Turnstile. CORS не считается аутентификацией. API-ключ внешней модели не нужен: применяется `env.AI.run`. `keep_vars: true` сохраняет переменные из Dashboard при Wrangler deploy.

Из корня свежей локальной копии: `npx wrangler deploy --config cloudflare/wrangler.jsonc`. GitHub Pages публикует только сайт; изменение worker.js в GitHub само по себе не меняет работающий Cloudflare Worker. После обновления поведения Пикси сервер нужно развернуть отдельно. Дополнительная `PIXIE_SYSTEM_PROMPT` сохраняется; общие правила персонажа добавляются к ней сервером. Игровой псевдоним VEDRO_AI_V2 и Нейрослопляндия — легенда, не заявление о фактической собственной архитектуре.

### Проверки и наклейка

`npm test` — тесты содержимого, интерпретатора, адаптера, защиты, SSE, личности и ограничений перемещения. `python tests/pix_browser.py` — Playwright с настоящими HTML/модулями, подменёнными облачными ответами. Проверяются приветствие без запросов, SSE/JSON, отмена, ошибки, unread, движение, клавиатура, мобильные размеры и наклейка.

Для среды, где запрещена любая браузерная навигация: `PIX_OFFLINE=1 CHROMIUM_PATH=/usr/bin/chromium python tests/pix_browser.py`. `tests/pix_harness.py` встраивает местные ресурсы и изолированно связывает ES-модули. Это локальная визуальная/поведенческая проверка, не тест реального CORS, провайдера или многодокументной навигации. `python tests/browser_smoke.py` отдельно покрывает переходы и учебные упражнения в CI. Тесты не расходуют квоты Workers AI.

Пользовательская наклейка оптимизирована в `assets/footer-sticker.avif`, расположена декоративным CSS-псевдоэлементом в правой колонке существующего футера и имеет прозрачный внешний фон. Семантика футера и ссылки не меняются. Структурные изменения футера по-прежнему делаются через `templates/footer.html`, затем `npm run chrome` синхронизирует девять документов.


### FAQ, контакты и состояния Пикси

FAQ использует пользовательские формулировки без названий модели и инфраструктуры. Краткое пояснение об обработке переписки и внешняя политика обработки данных остаются. Контакты автора хранятся в серверной PIXIE_PERSONALITY и добавляются даже при заданном PIXIE_SYSTEM_PROMPT. Ответ модели на произвольный вопрос не должен превращаться в рекламу автора; автоматической рассылки контактов нет. Проверки подтверждают наличие правил в собранной инструкции, но не гарантируют соблюдение каждой формулировки живой моделью.

Кадры вырезаны из предоставленного архива «Стикер-пак Пикс_ интерактивный гид АГА!.zip». Единый AVIF-спрайт 960×768 содержит 15 эмоций/действий и 5 кадров ожидания; оригинальные подписи и соседние рисунки не включены. manifest.json содержит координаты исходных областей. Прозрачный внешний шум удалён, персонаж не перерисован. Ростовой портрет 381×880 зарезервирован в HTML FAQ, поэтому его загрузка не сдвигает страницу.

Контроллер src/pix-moods.js независим от сетевого слоя. Первые 7 секунд сохраняется прежний приветственный аватар; затем непрочитанное сообщение получает собственную позу. Во время ответа приоритет у thinking/typing. В покое поза меняется через 24–48 секунд на 6,5 секунды. Одинаковая случайная поза не выбирается дважды подряд. Настройки движения и видимость вкладки останавливают таймеры, но события чата всё равно обновляют статичное изображение. Поездки в сеть ради эмоций не выполняются.

Проверки: npm test; CHROMIUM_PATH=/usr/bin/chromium python tests/pix_browser.py; python tests/polish_visual.py. Для среды, где запрещена навигация браузера, PIX_OFFLINE=1 включает имеющийся inline-harness. Это проверка реального локального кода/изображений, но не реальной сети, CORS или живой модели. PIX_CHECKS_OUT задаёт каталог снимков.

## Тема, мастерская и ошибки

`src/theme-init.js` подключается обычным синхронным скриптом перед CSS на каждой из девяти страниц. По умолчанию учитывается системная тема, переключатель сохраняет `aga-theme` в localStorage; события storage/pageshow сохраняют согласованность вкладок и переходов. `styles/theme.css` охватывает все страницы, форму, урок и виджет. Подключения управляются `npm run chrome`.

`src/pix-session.js` запоминает только факт показа приветствия в sessionStorage текущей вкладки. При заблокированном хранилище автоматическое уведомление отключено, чтобы не повторяться. Само приветствие остаётся локальным, сообщения нигде не сохраняются между страницами.

Мастерская: `src/workshop-core.js` валидирует и собирает четыре поля; явное нажатие «Собрать с Пикси» передаёт их чату через `aga:workshop-help`. Текст появляется в чате и в результате мастерской. Максимум последней пользовательской реплики — 3000 символов (остальная история по 1500), общий JSON — 24000 символов; обычный чат остаётся с полем на 1200. Кнопка локальной сборки не использует сеть. Отмена и сбой сохраняют поля.

`src/pix-errors.js` содержит закрытый набор пользовательских объяснений. Worker выдаёт только безопасный error.code из этого набора, не сообщения внешней модели. `cloudflare/ai-response.js` преобразует SSE в разрешённые текстовые события/ошибки, удаляя reasoning и метаданные. Подтверждённый отказ отделён от ошибки проверки, квоты и сетевого сбоя. Самостоятельно сгенерированный текст модели не считается служебной ошибкой. JSON fallback разрешён только при явном отсутствии поддержки стриминга, а не при отказе безопасности или произвольном сбое.

Проверки: `npm test`, `python tests/pix_browser.py`, `python tests/site_features_browser.py`. Последний проверяет 9 маршрутов, сохранение темы, приветствие один раз, передачу полей мастерской, ошибки и размеры 320/390/768/1440 в обеих темах. В ограниченном окружении можно использовать `PIX_OFFLINE=1`: это проверка настоящего кода во встроенном стенде с имитацией переходов/хранилища, не полноценная сетевая навигация. В CI запускается обычная навигация с моками только внешнего API, без расходования квоты ИИ.
