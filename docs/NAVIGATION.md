# Общая навигация

Глобальная шапка и футер находятся в `templates/header.html` и `templates/footer.html`. После редактирования запустите `node scripts/sync-chrome.mjs`; `--check` проверит, что фрагменты не разошлись. Страницы имеют рабочие статические ссылки без JavaScript; `src/site-chrome.js` добавляет мобильное меню, общий переключатель движения и продолжение знакомства. Вёрстка — `styles/chrome.css`.

Маршруты: `/` — главная; `/courses/` — практика; `/courses/start/` — знакомство; `/lessons/first-discovery/` — интерактивное занятие; `/math/` — математика для жизни; `/workshop/` — мастерская идей; `/library/` — подборка ресурсов; `/library/check-ai/` — статья о проверке результата ИИ.

Главная задача навигации — позволить зайти в АГА! не только через урок. Каждый пункт ведёт к реальному материалу; будущие курсы не изображаются готовыми. Сохраняйте ключи прогресса и совместимость старых ссылок. Все пути относительные, чтобы сайт жил под `/Teacher-/` на GitHub Pages.

На странице урока `.sidebar`, `main` и `.site-footer` — соседи внутри `.shell`. На широком экране панель занимает обе строки сетки, а урок с футером — правую колонку. Не выносить футер за пределы `.shell`: это ломает sticky-панель. На узком экране остаётся обычный поток.
