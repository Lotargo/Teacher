# Общая навигация

Шапка и футер находятся в `templates/header.html` и `templates/footer.html`. После изменений запустите `node scripts/sync-chrome.mjs`: он обновит статические фрагменты четырёх страниц между маркерами. `node scripts/sync-chrome.mjs --check` проверяет, что они не разошлись. Навигация работает без JavaScript; `src/site-chrome.js` только добавляет мобильное меню, общий переключатель движения и продолжение знакомства. Общий визуальный слой — `styles/chrome.css`. Ключи прогресса не изменены.
